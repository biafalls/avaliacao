# Desafio AGER

Projeto desenvolvido como desafio final do **Programa de Formação AGER 2026**.

A aplicação consiste em um sistema para gerenciamento de funcionários, agendas e compromissos, desenvolvido em Java com Struts 2 e persistência de dados utilizando JDBC.

O projeto contempla operações de cadastro, consulta, edição e exclusão, aplicação de regras de negócio, geração de relatórios em HTML e Excel, disponibilização de Web Services SOAP e testes unitários.
